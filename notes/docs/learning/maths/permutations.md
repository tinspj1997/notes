# Permutation

A permutation is an arrangement of objects in a specific order. 

## Types of Permutations

```mermaid
graph TD
```

### Odd Permutation
 - if number of swap is odd then it is called odd permutation.
### Even Permutation
 - if number of swap is even then it is called even permutation. 


## Transposition 
 - A transposition is a permutation that swaps two elements while keeping the rest unchanged.



## Permutation Formula (Without Repetition)

$$P(n, r) = \frac{n!}{(n-r)!}$$

## Permutation Formula (With Repetition)

$$P = n^r$$

## Permutation Formula (With Identical Items)

$$P = \frac{n!}{n_1! \times n_2! \times \dots \times n_k!}$$
